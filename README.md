Safeguard_Q

🎮 一款使用 C语言 + EasyX图形库 实现的塔防游戏。

📖 项目介绍

Safeguard_Q 是一款桌面端塔防游戏。玩家可以放置角色，抵御一波波敌人进攻，保护基地不被攻破。项目完整实现游戏主循环、敌人AI、塔攻击逻辑、碰撞检测、游戏UI界面。

📖 项目特点

职业单位除司令（Dan），核弹（小学长）外，

其他6个职业均由其他6位组员自由选择，以QQ头像作为游戏内建模图标，增加参与感

C语言大军：敌方单位，随板块知识难度提升，自身血量，防御攻击力均增强

（不是做题，而是以C语言学习内容命名的C语言军团）

核弹单位：由答对算法题解锁，玩中学，提升编程兴趣

✨ 功能特性

\- 完整游戏主循环，1280×720 游戏分辨率

\- 多种敌人类型，按路径自动移动

\- 可放置多类防御塔，自动锁定并攻击敌人

\- 血量、金币、波次计数等游戏状态管理

\- 游戏结束判定与基础交互逻辑

🛠 编译运行

环境依赖

\- Windows 系统

\- Visual Studio

\- EasyX Graphics Library

运行步骤

1\. 将项目全部文件下载到本地

2\. 使用 Visual Studio 打开 \`.sln\` 解决方案

3\. 确保已配置 EasyX 库

4\. 直接编译运行即可启动游戏
